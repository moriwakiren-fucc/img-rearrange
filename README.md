# 台紙メーカー

画像をアップロードすると正方形グリッドに自動配置し、PDFとしてダウンロードできるツールです。すべての処理はブラウザ内で完結し、画像はサーバーに送信されません。

## GitHub Pagesでの公開方法

1. このリポジトリ（`index.html` と `app.js` の2ファイル）をGitHubのリポジトリにそのままアップロードします。
2. リポジトリの **Settings → Pages** を開きます。
3. "Source" を `main`（または使用しているブランチ）、フォルダを `/ (root)` に設定して保存します。
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でアクセスできるようになります。

## 機能

- 用紙サイズ選択（B4横がデフォルト。B4/A4/A3/B5の縦横に対応）
- 複数画像の一括アップロード（大量枚数でも分割処理でクラッシュを防止）
- 画像枚数から自動でグリッドサイズ（n×n）を計算
- 余ったマスがまとまった枚数分ある場合、指定した枚数を2×2の大きな写真として表示可能
- 平均色をもとにした簡易的な色分散配置
- ドラッグ＆ドロップでの升目の入れ替え（マウス・iPad/iPhoneのタッチ両対応）
- 高画質PDFとしてダウンロード（画像枚数が多い場合は自動でDPIを調整し、生成処理が重くなりすぎないよう配慮）

## 技術構成

- 純粋なHTML/CSS/JavaScript（フレームワーク不使用）
- PDF生成: [jsPDF](https://github.com/parallax/jsPDF)（CDN経由で読み込み）
- フォント: Google Fonts（Zen Kaku Gothic New / Source Serif 4）

## 注意事項

- 通信環境がない場所ではフォントとPDFライブラリの読み込みに失敗する場合があります（インターネット接続が必要です）。
- 画像はすべてブラウザのメモリ上で処理されます。非常に大量（数百枚以上）の高解像度画像を同時に扱う場合、ご利用の端末のメモリ状況によっては動作が重くなることがあります。
